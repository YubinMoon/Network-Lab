# IPv4 Network Visualization Lab — Codex Implementation Pack

This repository documentation describes a browser-only educational network simulator focused on Layer 2 and Layer 3 IPv4 behavior.

The target user is an undergraduate student taking an Internet Protocol / Computer Networks course. The site is not a beginner textbook. It is an interactive lab where students build topologies and visually inspect how Ethernet, ARP, switching, IPv4 forwarding, routing tables, TTL, and ICMP ping work.

## Product summary

Build a browser-only web application where users can:

- Place `Host`, `Switch`, and `Router` nodes on a canvas.
- Connect nodes using `Link` objects.
- Let the app auto-detect `Network Segment` objects.
- Let the app auto-assign IPv4 addresses, MAC addresses, default gateways, connected routes, and auto-generated static routes.
- Send either `ICMP Echo` packets or `Generic IPv4 Packet` objects.
- Watch animated packet tokens move along links.
- Inspect exact Layer 2 / Layer 3 decisions through tables, logs, and binary prefix match views.
- Share the topology through URL-encoded state where possible.

## Hard constraints

- IPv4 only.
- UI technical terms must be English.
- No IPv6.
- No TCP or UDP simulation.
- No DHCP, DNS, NAT, VLAN, STP, RIP, OSPF, or BGP.
- Static routing is the actual routing behavior.
- Auto-generated routes are generated by the website for convenience, but they must appear as `Auto Static`, not as a routing protocol.
- Physical layer implementation details are out of scope.
- Layer 2 and Layer 3 behavior should be accurate enough for undergraduate computer networking education.

## Recommended stack

Use this stack unless there is a strong reason not to:

```bash
npm create vite@latest ipv4-network-lab -- --template react-ts
cd ipv4-network-lab
npm install @xyflow/react zustand lz-string nanoid clsx
npm install -D vitest @testing-library/react @testing-library/jest-dom jsdom
```

Recommended roles:

- `@xyflow/react`: canvas/node editor.
- `zustand`: global state management.
- `lz-string`: URL-safe topology compression.
- `vitest`: unit tests for IP utilities, segment detection, route generation, and packet simulation.

## Implementation order

1. Implement data types and IPv4/MAC utilities.
2. Implement topology editor with `Host`, `Switch`, `Router`, and `Link` objects.
3. Implement `Network Segment` detection.
4. Implement auto IPv4/MAC/default gateway assignment.
5. Implement connected route and auto static route generation.
6. Implement Layer 2 switching and ARP.
7. Implement IPv4 forwarding, TTL handling, route lookup, and longest prefix match.
8. Implement ICMP Echo and Generic IPv4 packets.
9. Implement animation and trace panels.
10. Implement URL-encoded topology export/import.
11. Add unit tests and example topologies.
